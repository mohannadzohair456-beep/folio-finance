# Folio — Private Personal Finance

Folio is an offline-first Android personal finance tracker with expense/income insights and optional user-authorized notification recognition. Financial data is kept on the device.

The `.github/workflows/build-apk.yml` workflow builds a signed APK for installation and future in-place updates when repository signing secrets are configured.

**Privacy:** Never commit Android signing keys, passwords, banking messages, or real transaction data. The repository is currently public; consider switching it to private in repository Settings.
